# MAFIA – Chicago 1925 · Noir Restoration v0.5

Browser-Spiel mit 1–4 lokalen Spielern. `index.html` starten. Der Ordner `assets` muss daneben liegen. Für GitHub/Vercel den **gesamten Ordnerinhalt inklusive assets/** hochladen.

## Neu in dieser Version
- 16 eigenständige monochrome SVG-Szenen (1200×600), echte externe Grafikassets.
- Komponierte instrumentale Noir-Begleitung als WAV-Datei (synthetisch erzeugte Originalkomposition).
- Bestehende interaktive Spielmechanik und Hotseat aus v0.4 übernommen.

## Grenzen / Transparenz
Die Illustrationen sind bewusst stilisierte Vektorgrafiken und keine handgemalten AAA-Illustrationen. Die Musik ist ein eigenständig algorithmisch arrangiertes Instrumental, kein aufgenommenes Jazzorchester. Die Karte und Spielregeln sind noch nicht binärgetreu aus dem C64 rekonstruiert. Diese Ausgabe ist **keine vollständige 1:1-Portierung**. Es wurden keine Original-C64-Grafikdateien als Assets ausgegeben.
